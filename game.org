* About This Doc
This file is the source of truth for the game. Rules for players live in [[file:rules.org][rules.org]], dated history lives in [[file:log.org][log.org]].

Conventions:
- Every system and component heading carries a status keyword: IDEA, DRAFT, TESTING, STABLE or CUT.
- Every system has a =CUSTOM_ID= starting with =sys-=, every component one starting with =cmp-=, every data table a =#+NAME= starting with =tbl-=.
- Link between them with =[[#sys-name]]= and =[[#cmp-name]]= so anything can be jumped to and found.
- Shared vocabulary: a /format/ is a physical shape and size, a /layout/ is a set of named /slots/ on a format, a /zone/ is a place on a board or mat where things go.
